## [0.1.0] - 2026-10-13

首个公开版本：后端 API、前端界面、演示数据脚本与容器化部署均已完整可用。

### 新增

- **后端（FastAPI，全异步）**：认证（JWT 登录、系统对接 API Key 换取令牌、个人资料 /
  头像 / 自助改密）、系统管理（用户 / 角色 / 权限 / 操作日志 / 管理员重置密码）、
  组织与员工、客户、商品（含分类 / 厂家 / 价格调整历史）、供应商、仓库、
  采购（订单 / 到货登记 / 部分收货 / 入库）、销售（订单 / 自动计价 / 发货出库 / 取消）、
  库存（查询 / 期初建账 / 全量流水）、退货、财务收款（登记 / 核销 / 应收账龄）、
  报表分析与经营看板。
- **GSP 合规闭环**：首营资质档案（证照审核 + 扫描件归档）、交易准入校验
  （证照过期 / 待审核 / 驳回时禁止下单收货）、到期分级预警中心、批次批号与效期管理、
  证照换证自动留档。
- **权限控制闭环**：接口级强校验（`require_permission`）+ 角色权限管理 +
  菜单与按钮联动；候选项数据拆到 `GET /api/options/{entity}`，登录即可访问且只返回
  id / 编码 / 名称，避免管理页敏感字段外泄。
- **前端（Vue 3 + TypeScript + Element Plus + Pinia + ECharts）**：全部业务页面、
  统一布局与路由守卫、统一业务对象选择控件（客户 / 商品 / 分类 / 厂家 / 供应商 /
  仓库 / 员工 / 部门）、列表分页与筛选。
- **演示数据**：`db/` 目录提供建库 / 造数 / 校验脚本，一次生成四年半（2022-01-01 ~
  2026-07-31）约 490 万条流水的可复现数据，参数集中在 `mock_params.py`。
- **容器化部署**：前后端 Dockerfile（非 root 运行 + 健康检查）、根目录
  `docker-compose.yml` 一键编排（**自带 PostgreSQL 17 与专属网络，不再依赖外部容器**）、
  专用 MinIO 对象存储、nginx 同源反向代理 `/api`、`.env.example` 部署参数模板。
- **数据库配置**：UTF-8 字符集 + ICU `zh-u-co-pinyin` 中文拼音排序，容器时区固定为
  `Asia/Shanghai`（避免「今日」类指标在 00:00~08:00 算成昨天）；容器化/本机安装、
  接入已有实例、备份恢复与常见问题见 [数据库部署与配置](docs/数据库部署与配置.md)。
- **协作模板**：GitHub Issue 表单与 PR 模板（`.github/`），英文说明 [README.en.md](README.en.md)。
- **测试**：后端 pytest 116 个用例；前端隔离环境 Playwright E2E 44 个用例；
  针对运行中部署的界面回归用例 58 个（`frontend/tests/live/`）。
- **文档**：中文 API 接口文档（126 个接口）、数据库结构分析、系统功能清单、
  GSP 合规闭环设计、权限控制说明、销售报表汇总表设计。

### 性能

- 销售报表改用预聚合汇总表，看板聚合下推 SQL；报表首屏由数十秒降到亚秒级
  （见 [docs/销售报表汇总表.md](docs/销售报表汇总表.md)）。

### 修复

- 库存列表分页总数、状态过滤顺序、报表分页缺失、非法分页参数 500 等一批分页与报表缺陷。
- 表格单元格统一单行显示、名称类列加宽，操作列不参与省略截断。
- GSP 证照扫描件大附件被 nginx 413 拦截。
- 运行环境回归用例「证照管理」依赖库里已存在证照，全新库上会失败——改为用例内临时建档并清理。

  [SECURITY.md](SECURITY.md)、[docs/许可与商用说明.md](docs/许可与商用说明.md)，重写
