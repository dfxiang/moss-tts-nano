## 常见问题

**公司内部使用需要付费或申请吗？**
不需要，也不属于「售卖本软件」。给客户免费部署、自己内部跑业务都没问题。

**我在它基础上做了一套系统卖给我的客户，可以吗？**
如果客户购买的是「你的产品与服务」，其价值主要来自你自研的部分，可以；
如果实际上卖的就是这套系统本身的功能，那属于不允许的情形——这也正是需要联系作者取得商业授权的情形。

**必须开源我的修改吗？**
不必须。Commons Clause 不是 copyleft 许可，你的二次开发可以保持闭源。

**这是「开源软件」吗？**
严格来说不是。Commons Clause 不在 OSI（Open Source Initiative）认证的许可列表里，
本项目属于 **source-available（源码可见）**：源码公开、可自由使用与修改、可免费再分发，
但限制「售卖」。GitHub 也会把它识别为自定义许可（Other）而不是 Open Source。
版权所有者（权利人本人）如果希望改用标准开源许可（例如纯 Apache-2.0 / MIT，此时他人可以售卖），
替换 `LICENSE` 即可；第三方无权更改本项目的许可。

**别人违反许可拿去卖，我能做什么？**
对方的使用授权在违反 Commons Clause 时即告终止，可要求其停止分发与赔偿。
同时请保留仓库中的版权与许可声明，这是维权的前提。
