# 医药销售管理系统功能清单

> 本文档基于对 `medsalesdb` 数据库的逆向分析（详见《数据库结构分析.md》），描述原应用系统应该具备的完整功能清单，用于指导系统重建或功能补全。
> 定位：医药销售（流通）公司的进销存 + 销售管理一体化业务系统。
>
> 移动端现状（2026-10-26）：Android 客户端已完成并发布 APK。支持经营首页、销售订单、库存查询、
> GSP 到期预警和个人资料。
> [观看演示视频](https://www.bilibili.com/video/BV1WtnQ6BE7F/) ·
> [下载 APK](https://github.com/dfxiang/med-sales/releases/tag/26.10.1) ·
> [构建与安全说明](../android/README.md)。

## 1. 系统定位与用户角色

### 1.1 系统定位

覆盖"采购 → 库存 → 销售 → 收款 → 退货 → 报表"全业务链路的医药流通企业核心业务系统，需满足 GSP（药品经营质量管理规范）对药品经营过程管理的基本要求。

### 1.2 用户角色

| 角色 | 主要职责 | 对应数据实体 |
| --- | --- | --- |
| 系统管理员 | 账号、权限、参数配置 | department/employee |
| 销售员/销售经理 | 客户维护、下单、跟进回款 | employee/sales_order/customer |
| 采购员 | 采购下单、到货跟踪 | purchase_order |
| 仓管员 | 入库、出库、库存管理 | inventory/inventory_movement |
| 质量员 | 商品资料、资质与质量管控 | product/manufacturer |
| 财务 | 收款登记、对账、应收管理 | payment_record/sales_order |
| 退货/客服 | 退货受理与处理 | sales_return |
| 管理层 | 查看报表、经营分析 | 各汇总视图 |

## 3. 功能清单详情

### 3.1 系统管理（建议新增）

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| SYS-01 | 用户账号管理 | 登录账号与员工档案关联 |
| SYS-02 | 角色与权限 | 按角色分配菜单/按钮权限（功能权限；不含数据级/行级权限） |
| SYS-03 | 登录认证 | 账号密码、验证码、登录锁定 |
| SYS-04 | 操作日志/审计 | 记录关键操作（下单、调价、删单、收款）的日志 |
| SYS-05 | 基础参数配置 | 单据编号规则、默认结算方式、默认仓库等 |
| SYS-06 | 数据字典管理 | 客户类型、合作等级、状态等枚举维护 |

### 3.2 组织与员工

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| ORG-01 | 部门管理 | 部门编码、名称、职责，支持区域销售部等层级 |
| ORG-02 | 员工档案管理 | 工号、姓名、部门、职位、上级、入职/离职状态 |
| ORG-03 | 组织架构图 | 按经理关系（manager_id）展示汇报链 |
| ORG-04 | 员工状态管理 | 在职/离职，离职后不允许再下单 |

### 3.3 客户管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| CUS-01 | 客户建档 | 编码自动生成，录入名称、类型、联系人、区域、证照号 |
| CUS-02 | 客户分类与等级 | 客户类型（医院/疾控/药房/诊所/经销商等）、合作等级 |
| CUS-03 | 信用额度管理 | 设置客户赊销额度（credit_limit），下单时校验未收金额是否超限 |
| CUS-04 | 客户状态管理 | 正常/冻结/流失/暂停合作；冻结客户禁止下单 |
| CUS-05 | 客户资质管理 | 许可证/营业执照编号及有效期跟踪（建议补充到期提醒） |
| CUS-06 | 客户查询 | 按编码/名称/类型/等级/区域/状态检索 |
| CUS-07 | 客户销售汇总 | 查看客户订单数、销售额、毛利、最近下单日期（对应 v_customer_sales_summary） |

### 3.4 商品管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| PRO-01 | 商品建档 | SKU、名称、分类、厂家、供应商、批准文号、规格、单位、剂型 |
| PRO-02 | 储存条件管理 | 常温/阴凉/冷藏 2~8℃/冷冻，冷链标识 |
| PRO-03 | 效期管理 | 有效期（月），结合批次记录跟踪（建议补充批次批号字段） |
| PRO-04 | 商品上下架 | 在售/下架（is_active） |
| PRO-05 | 商品分类管理 | 疫苗/药品/生物制品/中成药/耗材/设备分类，排序与启停 |
| PRO-06 | 生产厂家管理 | 厂家档案（名称、国家、简介） |
| PRO-07 | 成本与售价管理 | 采购成本价、挂网价/标准售价 |
| PRO-08 | 价格调整 | 调价单：旧价、新价、生效日期、原因（国家集采/挂网价调整/促销），写 price_history |
| PRO-09 | 商品查询与详情 | 按 SKU/名称/分类/厂家检索，展示价格历史 |

### 3.5 供应商管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| SUP-01 | 供应商建档 | 编码、全称、联系人、区域、证照 |
| SUP-02 | 结算账期设置 | credit_days（30/45 天等） |
| SUP-03 | 合作状态管理 | 合作中/暂停合作/已终止 |
| SUP-04 | 采购统计 | 按供应商统计采购额（建议新增视图） |

### 3.6 仓库管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| WAR-01 | 仓库档案 | 编码、名称、区域、仓管、联系方式 |
| WAR-02 | 冷链能力管理 | 是否具备 2~8℃ 冷链库 |
| WAR-03 | 仓库状态 | 正常/停用，停用仓库不可下采购/销售单 |

### 3.7 采购管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| PUR-01 | 采购订单创建 | 选择供应商、收货仓库，逐行选择商品、数量、单价，自动合计 |
| PUR-02 | 采购单编号 | 自动生成 PO+日期+序号 |
| PUR-03 | 采购单审核 | 金额/供应商资质校验（建议） |
| PUR-04 | 到货登记/收货 | 按明细登记实收数量、实收日期，支持部分收货 |
| PUR-05 | 采购入库 | 收货后生成"采购入库"库存流水并更新库存 |
| PUR-06 | 采购单状态流转 | 待收货 → 部分收货 → 已完成 |
| PUR-07 | 采购单查询 | 按供应商/仓库/状态/日期检索，查看明细与入库进度 |
| PUR-08 | 采购补货建议 | 根据库存预警与历史销量生成建议（建议新增） |

### 3.8 销售管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| SAL-01 | 销售订单创建 | 选择客户、销售员、发货仓库、结算方式、开票类型、配送方式 |
| SAL-02 | 订单明细录入 | 逐行选商品、数量，自动带出当日售价，支持行折扣率/优惠金额 |
| SAL-03 | 自动计价 | 成交单价 = 当日挂网价 × 折扣，行实付 = 单价×数量 − 行优惠 |
| SAL-04 | 金额汇总 | 自动计算小计、优惠、应收；保存成本合计用于毛利 |
| SAL-05 | 库存校验 | 下单/发货时校验仓库库存是否充足（库存不允许为负） |
| SAL-06 | 信用校验 | 按客户信用额度与应收余额校验赊销 |
| SAL-07 | 订单审核 | 大额订单或特价订单走审批（建议） |
| SAL-08 | 订单编号 | 自动生成 SO+日期+序号 |
| SAL-09 | 销售出库/发货 | 登记发货日期，生成"销售出库"流水并扣减库存 |
| SAL-10 | 订单状态流转 | 待付款 → 已付款/已发货 → 已完成；支持已取消 |
| SAL-11 | 订单取消 | 未发货订单可取消，已出库订单需先退货 |
| SAL-12 | 发票管理 | 记录开票类型（专票/普票/不开发票）与开票状态（建议补充发票号/开票日期字段） |
| SAL-13 | 订单查询 | 按客户/销售员/仓库/状态/日期/编号检索，支持订单详情追溯 |
| SAL-14 | 发货单/随货同行单 | 打印配送单据（建议） |

### 3.9 库存管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| INV-01 | 当前库存查询 | 按仓库/商品/分类查看库存数量与安全库存 |
| INV-02 | 库存状态标识 | 库存不足（< 安全库存）/库存预警（≤ 安全库存×1.2）/库存充足（对应 v_inventory_status） |
| INV-03 | 库存价值统计 | 按成本价计算库存金额 |
| INV-04 | 库存流水查询 | 按商品/仓库/类型/日期查询全量流水，穿透到来源单据 |
| INV-05 | 期初建账 | 系统启用时录入期初库存，生成"期初入库"流水 |
| INV-06 | 库存预警通知 | 低于安全库存自动提醒采购（建议） |
| INV-07 | 盘点管理 | 周期盘点与差异调整（建议新增，数据库无盘点表） |
| INV-08 | 批次/批号/效期管理 | 入库记录批次、生产日期、有效期，出库按先进先出（建议新增） |

### 3.10 退货管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| RET-01 | 退货单创建 | 选择原销售订单，带出客户、仓库、原成交价 |
| RET-02 | 退货明细 | 逐行登记商品、数量、原因（质量问题/效期临近/冷链断链/发错货/滞销退货/医院退回等） |
| RET-03 | 退货金额 | 按原订单成交价计算退货退款金额 |
| RET-04 | 退货单编号 | 自动生成 RT+日期+序号 |
| RET-05 | 退货处理 | 待处理 → 已完成 |
| RET-06 | 退货入库 | 处理完成后生成"退货入库"库存流水并增加库存 |
| RET-07 | 退款核销 | 退货金额冲抵订单应收或生成退款（建议与财务联动） |
| RET-08 | 退货查询 | 按订单/客户/原因/状态检索 |

### 3.11 财务与收款

| FIN-06 | 收款查询 | 按订单/客户/日期/方式/状态检索 |

### 3.13 GSP 合规与质量（建议补齐）

| GSP-01 | 首营资料管理 | 供应商/客户/商品/厂家证照、批准文号、注册证等资质档案与有效期跟踪；扫描件归档到对象存储（支持换证多版本留档） |
| GSP-02 | 证照到期预警 | 许可证、批准文号到期前自动提醒；预警中心按「已过期 / 30 天内 / 31-60 天 / 61-90 天 / 待审核资料」分级，并提供看板卡片 |

| GSP-05 | 效期预警 | 近效期商品提醒与禁止出库策略 |
| GSP-06 | 质量档案 | 质量问题、召回、不良反应记录 |

## 5. 建议实施分期

### 第一期（P0：核心闭环，先跑通业务）

1. 系统管理与权限（账号、角色、登录）
2. 组织与员工、客户、商品、供应商、仓库主数据管理
3. 销售订单全流程（下单 → 计价 → 出库 → 状态流转）
4. 库存管理（当前库存、库存流水、期初建账）
5. 采购订单与收货入库
6. 收款登记与订单核销
7. 每日/月度销售报表

### 第二期（P1：精细化与合规）

1. 价格调整单与审批
2. 客户信用额度校验
3. 退货退款核销、退货分析
4. 库存预警通知
5. 应收账龄分析、客户/销售员/商品报表
6. 操作审计日志
7. 批次批号与效期管理、证照到期提醒（GSP）

### 第三期（P2：扩展增强）

1. 盘点管理
2. 采购补货建议
3. 综合驾驶舱与图表可视化
4. 发货单/随货同行单打印
5. 冷链温度监控对接
6. 移动端应用（Android 已完成并发布 APK；后续按使用反馈迭代）

## 6. 与数据库的映射说明

功能清单中标注 P0 的功能均可在现有数据库结构上直接实现；以下功能需要**补充数据库结构**：

| 功能 | 建议新增字段/表 |
| --- | --- |
| 用户账号与权限 | users（账号、密码、角色）、roles、user_role、permission |
| 操作日志 | audit_log 表 |
| 发票信息 | sales_order 补充 invoice_no、invoice_date |
| 批次批号/效期 | batch 表（product_id、batch_no、生产日期、有效期、数量） |
| 盘点 | stocktake / stocktake_item 表 |
| 采购/销售审批 | 单据表补充审批状态与审批人字段，或单独审批流表 |
| 证照管理 | certificate 表（关联客户/供应商/商品，含到期日） |
| 通知提醒 | notification 表或集成消息通道 |

## 7. 结语

数据库设计完整、注释清晰、数据规模真实（4 年半、数百万级单据），为系统重建提供了良好基础。建议按"先核心业务闭环，再精细化与合规，最后扩展增强"的顺序推进，重建后的系统应以现有 18 张表 + 7 个视图为骨架，在其上补齐权限、批次、审计、预警等能力。
